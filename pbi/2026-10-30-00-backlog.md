## 外部比較の材料

ccusage (https://github.com/ryoppippi/ccusage) は 18 ソース対応: 各エージェント CLI
のローカルデータから daily / weekly / monthly / session / blocks（Claude Code の
5 時間課金ウィンドウ）のレポートを作る。`ccusage daily`（ソース指定なし）は検出された
全ソースを 1 つのレポートに統合する。statusline（Beta）もある。

一方 ccusage が持たず saniwalens が持つ独自価値: config surface × usage の join に
よる最適化ウェッジ（unused / costly+rare / never-fires rule / redundant /
friction）、failures / stuck / prompts の分析、`sql` による store 直読み、
`optimize` の配信 seam。ハーネス追加は「計測できる対象を広げる」ことで、
差別化を失わない。
